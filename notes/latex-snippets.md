# LaTeX snippets (quick reference)

Source: `.vscode/notes.code-snippets`. In a Markdown file: type the prefix, press **Tab**. Tab again jumps to the next placeholder.

| Prefix | Name | Expands to |
|--------|------|------------|
| `dm` | Display math | `$$ ⏎  ⏎ $$` |
| `im` | Inline math | `$$` |
| `al` | Aligned block | `$$ ⏎ \begin{aligned} ⏎  &=  \\ ⏎   &=  ⏎ \end{aligned} ⏎ $$` |
| `bf` | Bold | `\mathbf{}` |
| `bs` | Bold symbol | `\boldsymbol{}` |
| `bx` | bold x | `\mathbf{x}` |
| `bw` | bold w | `\mathbf{w}` |
| `bt` | bold t | `\mathbf{t}` |
| `by` | bold y | `\mathbf{y}` |
| `bX` | bold X | `\mathbf{X}` |
| `bphi` | bold phi | `\boldsymbol{\phi}` |
| `bPhi` | bold Phi | `\boldsymbol{\Phi}` |
| `bmu` | bold mu | `\boldsymbol{\mu}` |
| `bSig` | bold Sigma | `\boldsymbol{\Sigma}` |
| `RR` | Reals | `\mathbb{R}^{}` |
| `EE` | Expectation | `\mathbb{E}\left[\right]` |
| `Var` | Variance | `\operatorname{var}\left[\right]` |
| `NN` | Gaussian | `\mathcal{N}(x \mid \mu, \sigma^2)` |
| `pp` | Conditional p | `p(t \mid \mathbf{x}, \mathbf{w})` |

| `argmin` | argmin | `\operatorname*{arg\,min}_{\mathbf{w}}` |
| `argmax` | argmax | `\operatorname*{arg\,max}_{\mathbf{w}}` |
| `Tr` | Trace | `\operatorname{Tr}\left(\right)` |

⏎ = line break. Edit the snippet file to add or change entries, then update this table.
